# Churn Predictor

Predicts which telecom customers are likely to leave (churn).
This is the course project for the MLOps course; we improve it every session.

## Run it

```bash
python -m venv .venv
# Windows (Git Bash):  source .venv/Scripts/activate
# Mac / Linux:         source .venv/bin/activate
pip install -r requirements.txt
python get_data.py
python train.py
```
